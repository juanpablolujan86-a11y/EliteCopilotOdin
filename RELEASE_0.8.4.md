# ODIN 0.8.4 beta — diagnóstico de instalación

Actualización de mantenimiento basada en la beta 0.8.3. No incluye la integración experimental de Gemma ni los cambios de desarrollo posteriores.

- La preparación de Ollama guarda un registro completo con su versión, ubicación y errores de descarga.
- La ventana puede ampliarse y ofrece **COPIAR REGISTRO**.
- Si una descarga falla, la ventana permanece abierta para recuperar el diagnóstico.
- Conserva el acceso **Reparar reconocimiento de voz** del menú Inicio incorporado en la beta anterior. Ollama y el reconocimiento de voz son componentes distintos.

Descargá el instalador `ODIN-v0.8.4-beta-Setup-win64.exe`.

Los registros se generan en `%LOCALAPPDATA%\ODIN\logs`. Revisalos antes de compartirlos: pueden incluir rutas y nombres de usuario. No compartas archivos de configuración ni claves API.

Validación: 622 pruebas automáticas aprobadas. Esta beta mejora el diagnóstico; no garantiza resolver problemas de conexión o certificados del equipo. El instalador no está firmado digitalmente.
